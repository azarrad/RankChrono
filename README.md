# RankChrono
Overview

RankChrono is a research artifact for regression test prioritisation. It contains the experimental code, scripts, and supporting resources used to evaluate chronological and history-aware test prioritisation approaches.

Repository Contents

The repository includes:

Source code for the RankChrono approach.

Experimental scripts and evaluation procedures.

Supporting datasets and configuration files.

Scripts for reproducing the reported experimental results.

Requirements

The experiments were conducted using Jupyter Notebook. To reproduce the results, you will need:

Python and Jupyter Notebook installed.

The required Python libraries and dependencies used in the notebooks.

Repository Structure

All datasets required for the experiments should be uploaded to the folder named dataset.

Ensure that the datasets are placed in this folder and update the corresponding file paths in the Jupyter notebooks to reflect the repository structure.

Reproducing the Experiments

To reproduce the experimental results:

Clone or download this repository.

Ensure that all required datasets are uploaded to the dataset folder.

Open the relevant Jupyter Notebook files.

Check and update the dataset paths in the notebooks, where necessary, to point to the dataset folder.

Run all notebook cells sequentially, starting from the first cell and proceeding in order.

Allow each cell to finish executing before moving to the next one.

Following these steps will execute the experimental workflow and generate the corresponding results.

Artifact Availability

This repository is provided as supplementary material for research evaluation.
